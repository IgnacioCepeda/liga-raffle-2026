# Resultados del torneo

La app genera dos PDF y dos CSV desde el botón **Imprimir resultados** de la pantalla de clasificación:

- Resultados por equipos, con score neto, mejor score neto y HCPI promedio.
- Clasificación general de jugadores, con score neto, equipo y PHCP.

Al estar publicada en Vercel, el navegador descarga los archivos a la carpeta de descargas configurada en cada computadora. Los archivos no se pueden escribir automáticamente dentro de este directorio del servidor; una vez descargados se pueden copiar aquí para conservarlos junto al proyecto.
